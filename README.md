# JavaScript DOM Projects

A collection of beginner-friendly JavaScript projects built to practice **DOM manipulation, event handling, CSS styling, and basic JavaScript logic**.

## 🚀 Projects

### 1. Subscribe Button
A simple interactive subscribe button that changes its text and style when clicked.

**Features:**
- Toggle between `Subscribe` and `Subscribed`
- Dynamically add and remove CSS classes
- Uses `classList.add()` and `classList.remove()`

### 2. Amazon Shipping Calculator
A basic shipping cost calculator.

**How it works:**
- Enter the order cost
- Orders below `$40` get a `$10` shipping charge
- Orders of `$40` or more get free shipping
- Press **Enter** or click **Calculate** to see the total

### 3. Rock Paper Scissors
A simple Rock Paper Scissors game built using JavaScript.

**Concepts practiced:**
- Functions
- Conditional statements
- DOM manipulation
- Event handling
- User interaction
